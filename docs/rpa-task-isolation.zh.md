# RPA 任务隔离与停机

## Windows 更新

在原项目目录执行 `git pull --ff-only origin main`，停止旧 CapCut Mate 服务，再用原命令启动。无需新增依赖或手动增加环境变量。剪映保持打开并处于首页。

**一台 Windows 桌面只运行一个 CapCut Mate 服务进程**；不要使用多个 uvicorn worker，也不要同时启动两份服务控制同一个剪映。本次不是分布式调度改造。

## 执行方式

父进程只调度和维护任务状态。下载、剪映操作、上传各自在受监管的 Python 子进程中执行，配置继承服务环境。

| 阶段 | 并发上限 | 默认硬截止时间 | 异常处理 |
| --- | ---: | ---: | --- |
| 下载与本地校验 | 3 | 900 秒 | 失败，不进入 RPA |
| 首页就绪探测 | 与 RPA 共用 1 个槽位 | 15 秒 | 只读探测失败，不点击桌面 |
| RPA 导出 | 1 | 360 秒 | 终止本次执行子进程，保留剪映与草稿 |
| 上传与计费 | 2 | 600 秒 | 失败，不自动重试可能已产生副作用的上传/计费 |

父进程截止时间包含子进程启动、控制器初始化、COM/UI Automation 调用，以及导出内部重试。控制器原有 300 秒软超时仍保留。等待槽位的任务仅占协程，不占线程；队列读取也不使用执行线程池。

子进程通信使用私有临时 JSON 文件，校验阶段、草稿 ID 和随机调用标识；API key 不放命令行或进度文件。阶段子进程日志输出到启动终端，父进程阶段及终态日志仍保存在日志文件，避免 Windows 多进程共同轮转文件冲突。

## 一条卡死后

1. 当前任务返回 `failed`，包含具体错误，例如 `EXPORT_TIMEOUT`。
2. 只有本服务启动的阶段子进程会被终止，不按进程名杀 Python，不结束剪映，不点击“继续导出”，不删除失败草稿或可能仍由剪映写入的输出。
3. 已排队但尚未导出的任务返回 `RPA_NODE_NOT_READY`，不继续控制状态不明的桌面，也不无限等待。正在上传的独立任务可以继续。
4. 处理剪映异常弹窗并恢复到首页后，重新提交任务。新请求经过有界、只读首页探测通过后恢复导出，不需要重启 API 服务。
5. 如果操作系统无法确认执行子进程退出，执行器拒绝启动新进程，不能假装释放 RPA 槽位。

首页探测不主动切换页面、不关闭弹窗、不修改用户草稿。服务重启后的首次导出同样检查首页。

## 停止服务

正常停止（例如 Ctrl+C）会先停止接单，取消等待任务，终止本服务拥有的执行子进程并确认退出，再结束 worker。对外仍使用原来的四种任务状态；取消任务记为 `failed`，错误码为 `SERVICE_STOPPING`。

终止执行进程后，取消结果一次批量落库。数据库锁等待使用短预算；数据库不可写时会明确记录未持久化数量，不允许落库锁拖住子进程终止。失败结果在内存仍可查看，但未持久化的结果无法跨重启查询。

阶段子进程监测父服务退出：即使父 Python 被强制结束，也会自行退出，避免留下继续点击的自动化进程。强制结束无法保证任务终态落库，也不代表剪映自身导出已被取消。

停止时限默认 15 秒。无法确认清理完成会明确报 `SHUTDOWN_TIMEOUT` / `SHUTDOWN_FAILED`，不会虚报已停止。父进程故障、系统进程权限和 Windows 桌面状态仍需实际环境验收。

## 查询接口

`gen_video_status` 保持原字段兼容，增加：

| 字段 | 含义 |
| --- | --- |
| `phase` | queued、waiting_download、downloading、waiting_export、checking_node、exporting、waiting_upload、uploading、completed、failed |
| `phase_started_at` | 当前阶段开始时间 |
| `queue_position` | 已下载且正在等待 RPA 的序号，从 1 开始；其它阶段为 null |
| `node_error` | 节点最近的异常原因；新请求首页探测通过后清空 |

`progress` 仍然是阶段进度，不是剪映视频编码百分比。历史终态来自旧数据库时可能没有新阶段字段，不能据此伪造执行进度。

## 验证范围

自动测试模拟了超过默认线程池容量的 45 个任务、真实卡死 Python 子进程、超时后禁止继续导出、新请求恢复、下载/导出/上传阶段停止、重复取消、无输出禁止上传，以及 Windows 启动参数和 UIA 首页模型。

本地自动测试不等于真实剪映验收。Windows 更新后需要验证：正常草稿可导出；停止服务能退出；异常弹窗不会被跳过；恢复首页后新任务可执行。测试不得影响其它 Python 服务或自动关闭剪映。
